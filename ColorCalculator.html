sRGB → (감마 디코딩) → Linear RGB → (행렬 변환) → XYZ → (비선형화) → L*a*b* → (극좌표) → L*C*h°
① 감마 디코딩 — sRGB → Linear RGB
C' = CsRGB / 255
C' / 12.92 (C' ≤ 0.04045) ((C' + 0.055) / 1.055)2.4 (C' > 0.04045)
역방향(감마 인코딩): v ≤ 0.0031308 → 12.92·v, 그 외 1.055·v1/2.4 − 0.055
② Linear RGB → XYZ  (IEC 61966-2-1, D65)
X = 0.4124564·R + 0.3575761·G + 0.1804375·B
Y = 0.2126729·R + 0.7151522·G + 0.0721750·B
Z = 0.0193339·R + 0.1191920·G + 0.9503041·B
역방향(XYZ → Linear RGB) 역행렬도 IEC 61966-2-1 공식값 사용
Xn=95.047  Yn=100.000  Zn=108.883 (D65 화이트포인트)
③ XYZ → CIE L*a*b*
ε = 216/24389 ≈ 0.008856
κ = 24389/27 ≈ 903.3

∛t (t > ε) (κt + 16) / 116 (t ≤ ε)

L* = 116·f(Y/Yn) − 16
a* = 500·[ f(X/Xn) − f(Y/Yn) ]
b* = 200·[ f(Y/Yn) − f(Z/Zn) ]
④ CIE L*a*b* → L*C*h°
C* = √(a*2 + b*2)

h° = atan2(b*, a*) × 180π

h° ∈ [0°, 360°)  ·  C* = 0 이면 무채색
역방향: a* = C*·cos(h°)   b* = C*·sin(h°)
