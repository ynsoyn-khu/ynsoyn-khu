CIE L*a*b*  ·  CIE L*C*h°  ·  sRGB (D65)

3D 색 공간 시각화 — 드래그하여 회전  ·  흰 테두리 점 = 현재 색상
sRGB 색 공간
X=R  ·  Y=G  ·  Z=B
CIE L*a*b* 색 공간
X=+a*(Red)  ·  Y=L*  ·  Z=+b*(Yellow)
CIE L*C*h° 색 공간
Y=L*  ·  반경=C*  ·  각도=h°
변환 파이프라인 (클릭하여 수식 보기)
R, G, B ∈ [0, 255]  (8비트 정수)
HEX: #RRGGBB 표기
↓ 감마 디코딩
C' = CsRGB / 255
if C' ≤ 0.04045 → C' / 12.92
else → ((C' + 0.055) / 1.055)^2.4
↓ 행렬 변환 (IEC 61966-2-1, D65)
X = 0.4124564·R + 0.3575761·G + 0.1804375·B
Y = 0.2126729·R + 0.7151522·G + 0.0721750·B
Z = 0.0193339·R + 0.1191920·G + 0.9503041·B
(R,G,B는 Linear값, ×100 스케일)
↓ 비선형화 (CIE f 함수)
f(t): t > ε → ∛t  | t ≤ ε → (κt+16)/116
ε = 216/24389 ≈ 0.008856
κ = 24389/27 ≈ 903.3
L* = 116·f(Y/Yₙ) − 16
a* = 500·[f(X/Xₙ) − f(Y/Yₙ)]
b* = 200·[f(Y/Yₙ) − f(Z/Zₙ)]
↓ 극좌표 변환
C* = √(a*² + b*²)
h° = atan2(b*, a*) × (180/π)  ∈ [0°,360°)

① 감마 디코딩 — sRGB → Linear RGB
C' = CsRGB / 255
C' / 12.92 (C' ≤ 0.04045) ((C' + 0.055) / 1.055)2.4 (C' > 0.04045)
역방향(감마 인코딩): v ≤ 0.0031308 → 12.92·v, 그 외 1.055·v1/2.4 − 0.055
② Linear RGB → XYZ  (IEC 61966-2-1, D65)

역방향(XYZ → Linear RGB) 역행렬도 IEC 61966-2-1 공식값 사용
Xn=95.047  Yn=100.000  Zn=108.883 (D65 화이트포인트)
③ XYZ → CIE L*a*b*
ε = 216/24389 ≈ 0.008856
κ = 24389/27 ≈ 903.3

∛t (t > ε) (κt + 16) / 116 (t ≤ ε)

L* = 116·f(Y/Yn) − 16
a* = 500·[ f(X/Xn) − f(Y/Yn) ]
b* = 200·[ f(Y/Yn) − f(Z/Zn) ]
④ CIE L*a*b* → L*C*h°
C* = √(a*2 + b*2)

h° = atan2(b*, a*) × 180π

h° ∈ [0°, 360°)  ·  C* = 0 이면 무채색
역방향: a* = C*·cos(h°)   b* = C*·sin(h°)
